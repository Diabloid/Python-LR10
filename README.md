# Python-LR10: Лабораторна робота 10. Класифікація та регресія засобами scikit-learn

## Опис проекту
Репозиторій містить виконання Лабораторної роботи №10 з дисципліни Python:
- Дослідження та практичне застосування моделей машинного навчання бібліотеки `scikit-learn`.
- Частина 1: Класифікація (Logistic Regression, KNN, Decision Tree, SVC) на датасеті Iris.
- Частина 2: Регресія (Linear Regression, KNN Regressor, Decision Tree Regressor) на датасеті Diabetes.
- Аналіз метрик (Accuracy, Precision, Recall, F1, MAE, MSE, R²), Confusion Matrix, Decision Boundaries, Feature Importance.
- Дослідження впливу гіперпараметрів за допомогою крос-валідації.
- Інтерактивне прогнозування для нових користувацьких даних.
